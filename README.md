# Developer Portfolio - Modern Responsive Portfolio

A clean, modern, and fully responsive developer portfolio website built with HTML, Tailwind CSS, and JavaScript.

Live Demo: https://portfolio-1-three-fawn.vercel.app/
GitHub Repository: https://github.com/Mazzle003/portfolio-1.git

## Features

- Fully Responsive - Works perfectly on mobile, tablet, and desktop
- Modern UI - Clean design with backdrop blur effects and smooth animations
- Interactive Navigation - Mobile hamburger menu with blurred overlay
- Optimized Assets - SVG icons for fast loading
- Clean Code - Semantic HTML and utility-first CSS

## Tech Stack

- HTML5 - Semantic markup
- Tailwind CSS - For styling and responsiveness
- Vanilla JavaScript - For interactivity
- Vercel - For deployment

## Getting Started

1. Clone the repository
git clone https://github.com/Mazzle003/portfolio-1.git
cd portfolio-1

2. Open with Live Server
Open index.html with VS Code Live Server extension

3. If using Tailwind CLI
npx tailwindcss -i ./src/input.css -o ./dist/output.css --watch

- Desktop: 1024px and above

## Deployment

Deployed on Vercel.

To deploy your own:
vercel --prod

Or connect your GitHub repo at vercel.com/new
